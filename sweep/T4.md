### ding2026trace — TRACE: Temporal Rule-Anchored Chain-of-Evidence on Knowledge Graphs for Interpretable Stock Movement Prediction
- Citation: Q. Ding, H. Shi, L. Castejón Lozano et al., *TRACE: Temporal Rule-Anchored Chain-of-Evidence on Knowledge Graphs for Interpretable Stock Movement Prediction*, arXiv 2603.12500, 2026.
- Link: https://arxiv.org/abs/2603.12500 ; https://arxiv.org/html/2603.12500v1
- First public: 2026-03-12 (v1); Venue: preprint; Peer-reviewed: no
- Verification: [FT]
- Summary: Builds a temporal company KG with validity intervals per triple (42k nodes: Company, Event, Product, Person, Financial, TextSource; 174k edges; 11 relations such as SELLS, INVESTED_IN, ACQUIRED, SUED, CAUSED_INCREASE/DECLINE). It mines 2–4-hop relation-path rules by support/confidence (≥0.60), explores the KG along rule-admissible paths, grounds the paths in same-period news, and an LLM consolidates them into UP/DOWN verdicts with a readable evidence chain. Reports 55.1% accuracy on S&P 500 (487 stocks).
- Graph type: temporal (as-of filtered), heterogeneous, directed KG; text-grounded.
- Task: classification (next-day direction) + path explanation (rule mining = a form of KG reasoning).
- Data: S&P 500 OHLCV; news/earnings reports/filings, publishers not named. KG built 2022-01→2023-01, test 2023. Public? partly (prices yes, KG not released).
- Code available? not stated.
- What it leaves open: Evaluation is weak (my reading of the FT): one train year and one test year; rule-mining period not stated (possible leakage); defaults to DOWN when no rule fires (~15% of cases); the label is set before the LLM-validation step; agent baselines are self-built "proxies"; no transaction costs. The extractor used to build the KG is not described. Explanations are not evaluated for faithfulness.

### huang2026crossstock — Cross-Stock Predictability via LLM-Augmented Semantic Networks
- Citation: Y. Huang, Z. Fan, K. Hu et al., *Cross-Stock Predictability via LLM-Augmented Semantic Networks*, arXiv 2604.19476, 2026.
- Link: https://arxiv.org/abs/2604.19476 ; https://arxiv.org/html/2604.19476
- First public: 2026-04-21 (v1; v2 2026-04-26); Venue: preprint; Peer-reviewed: no
- Verification: [FT]
- Summary: Builds a top-K (K=5) cosine-similarity firm graph from 10-K risk-factor embeddings, updated yearly. DeepSeek-Chat (temperature 0, firms anonymised) then labels each candidate edge as competitor / supply_chain / complementary / substitute / peer / unrelated. Competitor edges are removed and substitutes down-weighted before pair-level mean-reversion signals are aggregated. The long-short Sharpe rises from 0.742 to 0.820 (S&P 500, 2011–2019).
- Graph type: temporal (annual snapshots), typed edges (multi-relational after LLM labelling), undirected.
- Task: other (graph refinement → return-signal construction / ranking).
- Data: CRSP (licensed), SEC 10-K text (public). Public? partly.
- Code available? not stated.
- What it leaves open: No human validation or accuracy figures for the LLM edge labels. The effect of the label taxonomy, the LLM choice and K on the result is not studied. LLM look-ahead/memorisation is not tested beyond anonymisation. No transaction costs. Sample ends in 2019.

### fukada2026snippetdriven — Snippet-Driven Supply Chain Discovery with LLMs: Scaling Visibility in China

  - Supply chains: PMGraph.
  - Proprietary data is common: FactSet, PitchBook, CSMAR, CRSP, enterprise KGs.
- **Typical evaluation weaknesses:**
  - Random rather than temporal splits for link-type tasks (InterCorpRel firm-level 9:1; MIRAGE-VC 70:15:15).

  - No transaction costs (TRACE, huang2026).

  - Self-implemented "proxy" baselines (TRACE). Simulation-only evidence (zhang2026llmenhanced).
  - Proprietary data blocks replication (InterCorpRel, MIRAGE-VC, li2025heterogeneous).
- **Verdict: moderate overall, but uneven.**
  - **Crowded:** "LLM extracts a financial KG → RAG/HGNN → stock trend or QA" (≥10 papers in 2025–26, several workshop-level, one ICLR 2026 rejection). Another such pipeline would not be a niche.
  - **Thin:**

    - Heterogeneous company graphs for credit contagion with public data.
    - Rigorous evaluation of path explanations.
    - Investor–company link prediction with modern temporal heterogeneous GNNs on public data.
  - The thin areas match the supervisor's profile (knowledge networks, text analysis, VC investment graphs).

## D. Open gaps and niche ideas

1. **Temporal KG completion on a public company KG ("which firm relations appear next year?").**
   - Gap: FinReflectKG's released KG (743 S&P 500 firms, 2014–2024, 17.5M triples with start/end dates, CC-BY-NC) has been used only for QA/retrieval (MultiHop) and extraction evaluation (EvalBench). The authors list temporal KGs as future work.
   - Gap: InterCorpRel shows supplier-link prediction works, but on proprietary FactSet, a single 2023 snapshot and a random split. FinDKG (2024) is the only financial TKG link-prediction study.
   - Thesis: build a time-sliced company subgraph (Supplies, Partners_With, Has_Stake_In, Competes/ORG–ORG edges). Benchmark TKG extrapolation (rule-based, e.g. TLogic-style; RE-GCN-style; recurrent heterogeneous GNN; an LLM baseline with a post-cutoff test year) under strict *year-ahead* splits with time-aware filtered metrics.
   - Second contribution: test whether *predicted* new edges carry return or co-movement information, the validation logic of huang2026.
   - Revealed by: arun2025finreflectkg, arun2025finreflectkgmultihop, sun2025intercorprelllm, li2024findkg.
   - Supervisor fit: high (KGs + text).

2. **"Extraction multiverse": how LLM-extraction choices change the company graph and downstream conclusions.**
   - Gap: FinReflectKG modes produce measurably different graphs (reflection = more compact and compliant; single-pass = more faithful). Wesslund et al. show static vs induced ontologies drift differently and that hallucination rates swing 65%→1.6% depending on verification. Snippets vs full text change yields (fukada2026). huang2026 never validates its LLM edge labels.
   - Thesis: fix a corpus (e.g. 10-Ks of ~100 firms over several years). Build K graphs by varying LLM, ontology (closed vs induced), extraction mode, entity-resolution threshold and anonymisation.
   - Measure graph-level divergence: edge Jaccard, degree/centrality rank stability, community NMI.
   - Measure downstream variance: link prediction from idea 1, or cross-stock return predictability as in huang2026.
   - Include a small human-annotated gold set and a look-ahead test (pre- vs post-LLM-cutoff filings).
   - A clean, reproducible, novel evaluation-rigour contribution, not "yet another model".
   - Revealed by: arun2025finreflectkg, dimino2025finreflectkg, wesslund2026llmbased, fukada2026snippetdriven, huang2026crossstock, ding2026trace.

3. **Credit-event contagion into equity over a heterogeneous company graph built from public text.**
   - Gap: default-propagation work uses proprietary enterprise KGs (li2025heterogeneous) or bank-only similarity multiplexes with CDS (umeorah2026temporal). zhang2026llmenhanced proposes event propagation over LLM-built firm graphs but tests only on simulations.
   - Thesis: take public credit events (my suggestion: SEC 8-K Item 1.03 bankruptcy filings and rating-related 8-K items; data availability to be checked) as shocks on a FinReflectKG-derived heterogeneous graph (Supplies / Has_Stake_In / Partners_With / shared risk factors).
   - Test whether neighbours' abnormal returns depend on relation type and path length, as an event study plus a temporal heterogeneous GNN or diffusion model.
   - Output: per-relation-type contagion coefficients and explanation paths.
   - Revealed by: li2025heterogeneous, umeorah2026temporal, zhang2026llmenhanced, arun2025finreflectkg.
   - Links to the credit-default theme of the overall thesis.

4. **Faithful, temporally honest path explanations for analysts.**
   - Gap: TRACE produces rule-anchored KG paths but has a single test year, an unclear rule-mining period, a default-DOWN fallback, and no faithfulness test. MIRAGE-VC produces reasoning chains with no rationale evaluation. OntoKG-EQ and lee2025knowledge show only case studies or a small trust survey.
   - Thesis: walk-forward rule mining strictly on past windows over a public temporal company KG.
   - Measure *rule decay* (how fast mined relation-path rules lose confidence year to year).
   - Evaluate explanation faithfulness with deletion/insertion tests on paths and compare with GNNExplainer-style subgraph explanations of a heterogeneous GNN.
   - Optionally add a small analyst study.
   - Revealed by: ding2026trace, pei2025gaining, nasir2026ontokgeq, lee2025knowledge.

5. **Investor–company temporal heterogeneous graphs with public data (supervisor's Crunchbase line, modernised).**
   - Gap: the VC-graph papers (MIRAGE-VC, SimVC-CAS) rely on PitchBook. yu2025staged does investor→company link prediction with Node2vec only. MIRAGE-VC states that open Crunchbase data ends in 2013.
   - Thesis: a public-data analogue for *listed* firms. Institutional holders → stocks from SEC 13F filings (quarterly bipartite, temporal). This is my suggestion; I found no 2025–26 13F-graph paper in this sweep, but search was budget-limited, so the T4 crowding check here is weak.
   - Tasks: (a) temporal link prediction of fund entry/exit; (b) anomaly detection of crowded or coordinated holding changes; (c) heterogeneous extension with FinReflectKG company–company edges, testing whether KG relations help predict co-holding.
   - Revealed by: pei2025gaining, liu2025beyond, yu2025staged.

6. **Temporal heterogeneous anomaly detection on company graphs, with label-noise awareness.**
   - Gap: FiGraph (WWW'25) offers 9 yearly heterogeneous snapshots with labels that change over time, and KeGCN_R shows the "information overload" and hidden-fraud problems. Both are China-only, and FinFraudBench is transaction-level.
   - Thesis: benchmark temporal heterogeneous GAD on FiGraph with strict forward-in-time evaluation and PU-learning (positive-unlabelled) or noisy-label methods.
   - Optional transfer: a US analogue using SEC AAER enforcement labels (my suggestion; public) and FinReflectKG relations.
   - Revealed by: wang2025figraph, wang2025corporate, FinFraudBench (excluded, protocol only).

7. **Emerging entities (IPOs, spin-offs, renamed firms) in company TKGs.**
   - Gap: every company-KG paper above treats the entity set as fixed. TransFIR (ICLR 2026, seen via OpenReview record only) targets TKG reasoning for entities without history.
   - Thesis: inductive TKG completion for newly listed firms, using 10-K text as cold-start features. This can be a sub-question of idea 1.
   - Revealed by: arun2025finreflectkg (firm set grows 2014→2024), sun2025intercorprelllm (fully inductive test set has only 95 positive pairs).
